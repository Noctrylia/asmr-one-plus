# asmr.one plus

简体中文 | [English](./README.en.md)

asmr.one 增强用户脚本，提供播放进度保存、播放历史、本地关注和数据管理功能。

当前版本：**1.2.0**

支持中文、日文和英文，跟随网站的语言设置。

## 脚本新增功能

### 播放进度

记录每条音频的播放位置，再次播放时从上次的位置继续。播放期间每 5 秒保存一次，暂停、切换音频或离开页面时立即保存。

### 播放历史

开始播放后，作品立即加入历史记录，最多保留最近 200 部作品。可从历史中继续播放，也可删除单条记录或清空历史。

### 本地关注

收听作品时，可关注喜欢的声优、标签和社团，日后从“我的关注”进入相关作品列表，便于再次查找和浏览。支持分组、批量添加和按作品数量排序；批量添加时，多个名称用分号分隔。

### 仅单人出演

按一位声优筛选作品时，可在排序旁开启“仅单人出演”。凑满一页后会先显示作品，后台继续读取演出名单。查完后显示准确总数和页码，之后可直接跳页。除末页外，每页按所选数量显示。

只有开启“仅单人出演”后才读取单人结果，普通声优列表不自动预取。关闭筛选或离开列表会取消尚未完成的读取。完整结果在浏览器本地缓存五分钟，最近三组搜索刷新后仍可复用；超时后重新读取。首次没有缓存的搜索仍需等待接口响应。

开启时复用普通列表已经加载的数据，并按作品总量安排读取，首屏小请求与完整结果共享最多四路并发。可复用的数据已凑满一页时，首屏无需等待新请求；准确总数和完整页码仍在整组读取完后显示。[性能验证与接口限制](./docs/solo-performance.md)

缓存按站点、接口、账号和搜索条件隔离，不保存登录令牌、收藏夹标记和个人评分，也不进入备份。启用收藏夹快捷标记时同样可以复用缓存，标记和个人评分只在当前页后台更新，更新完成前不显示旧标记。清除全部脚本数据会一并清除当前站点的单人搜索缓存。

### 数据管理

新增独立的“数据管理”页面，集中提供关注、历史和播放进度的备份与导入，以及清除全部播放进度、清除全部脚本数据。

## 原站界面调整

原站的功能命名与实际用途存在混淆：“播放列表”承担作品收藏功能，“我的收藏”实际汇总评分、评论和收听状态。脚本按实际用途纠正命名：

- 原“播放列表”改为 **“收藏夹”**，用于收藏和整理作品。
- 原“我的收藏”改为 **“我的标记”**，汇总评分、评论及“想听”“在听”“听过”等状态。

另外，在移出收藏夹前增加确认，减少误操作。

为播放器底部图标添加悬停提示，说明播放队列、播放模式、桌面字幕、字幕选择和更多操作。

## 安装与更新

1. 安装并启用 Tampermonkey，按浏览器提示开启用户脚本权限。
2. 打开 [Sleazy Fork 脚本页](https://sleazyfork.org/zh-CN/scripts/603419-asmr-one-plus)，点击“安装此脚本”并确认。
3. 刷新网站，侧栏将新增“我的关注”“播放历史”和“数据管理”。

通过 Sleazy Fork 安装后，Tampermonkey 会按设置检查更新，也可在管理面板中手动检查，无需卸载旧版。

## 数据说明

- 关注、历史和播放进度保存在脚本管理器本地，不自动上传。同一脚本实例下的网站账号共用这些数据，跨浏览器或设备需通过备份文件迁移。
- 历史与播放进度独立清除。音频列表可清除单条进度，同一音频的其他格式会一并清除；清除正在播放的音频进度后，音频暂停并回到开头。
- 备份包含个人收听记录，不包含登录令牌。卸载脚本或清空扩展数据前，请先导出备份。

## 开发

使用 Node.js 22 或更新版本：

```sh
npm ci
npm run build
```

源码位于 `src/`，构建产物为根目录的 `asmr-one-plus.user.js`，安装仅需该文件。版本号和脚本配置统一在 `package.json` 中维护。

维护参考：[asmr.one 技术栈](./docs/site-stack.md)（英文）。
