新增单人出演筛选，并优化加载与缓存。

- 按一位声优搜索时，可开启“仅单人出演”，排除合作作品。
- 支持准确作品总数和固定分页，除末页外按所选数量显示。
- 首屏优先展示，完整结果本地缓存五分钟；普通浏览不自动预取，关闭筛选后取消未完成请求。
- 收藏夹标记独立更新当前页，正式安装文件使用 Sleazy Fork 更新地址。

首次无缓存时仍需读取出演名单，不能保证即时完成统计。

Adds solo voice actor filtering with exact totals and fixed pagination. Results load on demand, prioritize the first page, and cache complete searches locally for five minutes. Ordinary browsing does not prefetch; disabling the filter cancels unfinished requests. Collection marks refresh separately for the current page.

An uncached search still needs to read the cast lists before exact totals are available.
